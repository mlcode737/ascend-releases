# Ascend releases

Windows installers for **Ascend**, a personal progression app for habits and quests.

Download the latest version from the [Releases page](https://github.com/mlcode737/ascend-releases/releases/latest) or from the Ascend website.

- Requires Windows 10 or 11, 64-bit.
- The installer isn't code-signed yet. If Windows SmartScreen warns you, choose **More info**, then **Run anyway**.
- Each release lists the installer's SHA-256 checksum. To check a download in PowerShell: `Get-FileHash .\Ascend-Setup-<version>.exe`
- Updating: run the newer installer. Your data in `%APPDATA%\Ascend` is kept.

This repository holds release files only.
